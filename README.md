Entry for the [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2) bounty on make.fun.

The program writes exactly one word to `/output/entry.txt`: the word an
ex would use to describe the entrant.

**Roommate** — the relationship didn't end in a fight, it ended in a
flat-share: two people splitting rent and silence. Painfully honest,
instantly relatable, and funnier than any insult because it's true.

Run it with Node 22:

```
node main.ts
```

It writes `Roommate` (8 characters, one word) to `/output/entry.txt`.
